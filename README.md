# Prague Parking V1

## Beskrivning
Ett parkeringsprogram utvecklat i C# med Visual Studio och .NET 10. Programmet hanterar parkeringsplatser och fordon via en konsolmeny.

## Funktioner
- Parkera fordon
- Söka efter fordon
- Hämta ut fordon
- Flytta fordon
- Avsluta programmet

## Teknik
- C#
- .NET 10
- Visual Studio

## Syfte
Projektet är en skoluppgift för att utveckla kunskaper inom C#, med fokus på arrayer, loopar, villkor och metoder.
